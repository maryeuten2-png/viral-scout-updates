# Viral Scout Updates

Минимальный канал обновлений Viral Scout.

- `scout.py` — текущая версия панели и Scout Core.
- `START.bat` — запуск с автоматическим обновлением.

Обычная работа: пользователь запускает локальный `START.bat`; он забирает последнюю версию `scout.py` из этого репозитория и открывает панель. Локальный `selected.json` не обновляется и сохраняет выбранные ролики.

Принцип проекта: минимум функций, максимум полезности.
